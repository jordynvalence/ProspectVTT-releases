# Prospect VTT for Windows

## [⬇ Download the latest version](https://github.com/jordynvalence/ProspectVTT-releases/releases/latest)

On that page, under **Assets**, click **Prospect-VTT-Setup-<version>.exe**. Ignore the other files; the app uses them to find updates.

## Install
1. Run the Setup file you downloaded.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The installer isn't code-signed yet, so Windows doesn't recognize it.
3. Follow the steps. Prospect VTT opens when it's done.

## Updates
The app checks for a new version when it starts. You can also check yourself: ☰ → Settings → Desktop app → **Check for updates**. When a download finishes, click **Restart now**, or **Later** to install it the next time you close the app. Your campaigns stay where they are.

## Uninstall
Windows Settings → Apps → Installed apps → Prospect VTT → ⋯ → **Uninstall**. Your campaigns in `%APPDATA%\Prospect VTT` are kept. Delete that folder too if you want everything gone.

All past versions are on the [Releases](https://github.com/jordynvalence/ProspectVTT-releases/releases) page.
